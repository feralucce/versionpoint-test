Lesson 36 minutesThe review copy, in Word

What your reviewer gets (Word)

Open the review copy the way Riley Planner will, and know what to tell a reviewer before they start.

Why it matters

Your reviewers never see VersionPoint. If you can tell them what to expect in Word, they send back a file that comes in cleanly, and you spend less time chasing edits.

Watch

How the copy travels

In your office, the review copy goes to the reviewer as an attachment to your own email, and the reviewer sends the same file back the same way. VersionPoint never emails anyone. All it needs is the file that comes back.

In this course there's no one to email, so the reviewer's desk plays the reviewer. You give it the copy you downloaded, it makes Riley Planner's edits and margin notes on it the way Word would, and you download Riley's returned file. Everything happens in your browser.

Practice files
  • The reviewer's desk: plays the reviewer on a copy you downloaded.

The copy, opened in Word

The lock has a password, but nobody has it. VersionPoint makes a random one for each copy and doesn't keep it. That's on purpose: no one can switch tracking off and fix things quietly.

What the reviewer does

  • Edits as usual. Every edit is tracked in their name.
  • Adds comments in the margin, and replies to other people's comments.
  • Saves, and sends the same file back. The name can stay as it is.
What to tell your reviewer

Paste this into your email when you send a review copy:

Edit in this file. Track Changes is on. Add comments in the margin. Save and send this same file back. Please don't copy the text into a new document.

Try it

  1. Open the review copy you kept in lesson 2, Lake Shuttle news release - for Riley Planner - round 1.docx, in Word.
  2. Choose the Review tab. Track Changes is on, and Word won't let you switch it off.
  3. Choose Restrict Editing on the Review tab. The pane says the document only allows tracked changes. Don't choose Stop Protection: it asks for a password nobody has.
  4. Look through the margin and the text. There are no comments and no tracked changes.
  5. Choose File, then Info. Under Properties, there's no author and no Last Modified By name.
  6. Close the copy without saving it. Leave it as VersionPoint made it.
  7. Open the reviewer's desk from the practice files above. Leave Reviewer on Work it out from the file name.
  8. Choose Choose the copy you downloaded, then choose the review copy. The desk says Riley Planner sent it back and lists what Riley did.
  9. Choose Download the returned file. It has the same name as the copy, so your browser may add a number to it. The newest file is Riley's.
  10. Open Riley's returned file in Word. Riley's edits are tracked in Riley's name, with three comments in the margin and Drew Grants's reply on the grant name. Close it without saving, and keep it for lesson 4.

Check your work

Watch out for

A reviewer pastes the text into a new file. It comes back without the copy mark. VersionPoint compares it with the copy anyway, and warns you (lesson 4).
The lock gets taken off, for example by an editor that ignores it. VersionPoint says so when the file comes back, and still finds every edit made without tracking. Riley's file does this on purpose.
A reviewer sends back last round's copy. VersionPoint turns it away and says whose copy it is, so nothing old slips in.
Don't edit or save the copy yourself before it goes out. Send it as VersionPoint made it. If you need a change of your own, that's Edit it yourself (lesson 7).
