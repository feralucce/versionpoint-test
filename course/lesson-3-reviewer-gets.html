Lesson 36 minutesThe review copy, in Word

What your reviewer gets (Word)

Open the review copy the way Riley Planner will, and know what to tell a reviewer before they start.

Why it matters

Your reviewers never see VersionPoint. If you can tell them what to expect in Word, they send back a file that comes in cleanly, and you spend less time chasing edits.

Watch

How the copy travels

In your office, the review copy goes to the reviewer as an attachment to your own email, and the reviewer sends the same file back the same way. VersionPoint never emails anyone. All it needs is the file that comes back.

In this course there's no one to email, so the reviewer's desk plays the reviewer. You give it the copy you downloaded, it makes Riley Planner's edits and margin notes on it the way Word would, and you download Riley's returned file. Everything happens in your browser.

Practice files
  • The reviewer's desk: plays the reviewer on a copy you downloaded.

The copy, opened in Word

Track Changes is on, but the reviewer can switch it off. That's fine: when the file comes back, VersionPoint compares it with the copy word by word, so every edit is listed, tracked or not, and credited to the reviewer. If you tick Lock Track Changes on in Send for review, Word keeps tracking on and the reviewer can't switch it off. Lock it only for a reviewer on desktop Word: Word in a web browser, such as from Outlook on the web, can't edit a locked copy.

The copy mark

Each copy carries its own ID, VersionPoint's copy mark, in two places. That's how VersionPoint knows which round a returned file belongs to.

  • In the file's properties: the property named VersionPoint above.
  • In the text, as hidden marks: invisible characters at the end of each paragraph with real text. They don't change how the release looks, Word's word count, or what Find finds.

Because the hidden marks travel with the text, a reviewer who saves the copy as a new file, or pastes the text into one, usually still sends back a file VersionPoint can match to this copy, with no warning. Only a file whose text was retyped, or cleaned of invisible characters, loses both (lesson 4).

What the reviewer does

  • Edits as usual. Every edit is tracked in their name.
  • Adds comments in the margin, and replies to other people's comments.
  • Saves, and sends the same file back. The name can stay as it is.
What to tell your reviewer

Paste this into your email when you send a review copy:

Edit in this file. Track Changes is on: please leave it on. Add comments in the margin. Save and send this same file back.

Try it

  1. Open the review copy you kept in lesson 2, Lake Shuttle news release - for Riley Planner - round 1.docx, in Word.
  2. Choose the Review tab. Track Changes is on. Leave it on.
  3. Look through the margin and the text. There are no comments and no tracked changes, and the hidden marks don't show.
  4. Choose File, then Info. Under Properties, there's no author and no Last Modified By name.
  5. Close the copy without saving it. Leave it as VersionPoint made it.
  6. Open the reviewer's desk from the practice files above. Leave Reviewer on Work it out from the file name.
  7. Choose Choose the copy you downloaded, then choose the review copy. The desk says Riley Planner sent it back and lists what Riley did.
  8. Choose Download the returned file. It has the same name as the copy, so your browser may add a number to it. The newest file is Riley's.
  9. Open Riley's returned file in Word. Riley's edits are tracked in Riley's name, except September 27, which Riley fixed with Track Changes switched off. There are three comments in the margin and Drew Grants's reply on the grant name. Close it without saving, and keep it for lesson 4.

Check your work

Watch out for

A reviewer switches Track Changes off. VersionPoint still finds every edit by comparing the file with the copy, and marks those edits Made without Track Changes. Riley's file does this on purpose (lesson 4).
A reviewer pastes the text into a new file. The hidden marks usually come along, so VersionPoint matches it to the copy with no warning. Their edits weren't tracked in the new file, so they all come in marked Made without Track Changes.
A locked copy for a reviewer on Word in a web browser. They can't edit it. Leave Lock Track Changes on unticked unless the reviewer uses desktop Word.
A reviewer sends back last round's copy. VersionPoint turns it away and says whose copy it is, so nothing old slips in.
Don't edit or save the copy yourself before it goes out. Send it as VersionPoint made it. If you need a change of your own, that's Edit it yourself (lesson 7).
